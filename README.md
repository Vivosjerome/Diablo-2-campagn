# D2R — Maphack Mental

Guide de navigation rapide et check-list de campagne pour **Diablo II Resurrected**.

Ouvre `index.html` dans un navigateur. La progression est sauvegardée localement (aucun compte).

L’icône **Tuiles** à droite ouvre un mini-jeu : une carte de donjon est générée, tu choisis l’une des 4 zones où se trouve la sortie (règle des 90° à gauche).

## La règle d'or

À l'entrée d'un donjon, lis l'axe du **couloir** (pas le personnage). La sortie est à **90° vers la gauche** (anti-horaire) dans la plupart des donjons clos.

## Lancer en local

Double-clic sur `index.html`, ou :

```bash
npx --yes serve .
```
